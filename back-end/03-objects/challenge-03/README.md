## Prompt

Create a function called `formatInventory(inventory)` that receives an object where each key is a product name and each value is the quantity available.

Return an array of strings in this format:

```text
product: quantity
```

## Examples

```javascript
formatInventory({ apples: 4, bananas: 2 });
// ["apples: 4", "bananas: 2"]

formatInventory({ notebook: 3 });
// ["notebook: 3"]
```
