# Objects

Object-focused JavaScript challenges.

These exercises are local to this repository. Each challenge has its own folder. Open the challenge folder, read its `README.md`, implement the requested function in `challenge.js`, and paste the final solution into the `Solution` section.

Follow the order below. The first 8 challenges are easy, and the last 2 are medium/hard.

## Running Tests

Each challenge folder has a `challenge.js` file for the implementation and a `challenge.test.js` file with native Node.js tests.

Run all object challenge tests with:

```bash
npm run test:objects
```

No external libraries are required.
