## Prompt

Create a function called `createPriceMap(products)` that receives an array of product objects.

Each product has this shape:

```javascript
{ name: "Keyboard", price: 120 }
```

Return an object where each key is the product name and each value is the product price.

## Examples

```javascript
createPriceMap([
  { name: "Keyboard", price: 120 },
  { name: "Mouse", price: 80 }
]);
// { Keyboard: 120, Mouse: 80 }
```

- Use `Object.fromEntries`.
