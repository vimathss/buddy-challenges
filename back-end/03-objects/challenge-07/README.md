Context: Objects

Difficulty: Easy

Status: Not started

Methods to practice: `Object.values`

## Prompt

Create a function called `countValueTypes(data)` that receives an object and returns another object counting how many values of each JavaScript type exist in `data`.

Use the result of `typeof` as the count key.

## Examples

```javascript
countValueTypes({
  name: "Ana",
  age: 22,
  active: true,
  city: "Recife"
});
// { string: 2, number: 1, boolean: 1 }

countValueTypes({});
// {}
```

## Requirements

- Use `Object.values`.
- Return a new object.
- Do not include types with count `0`.
