# JavaScript Challenge Lists

This folder contains JavaScript exercises organized by context.

The numbered folders define the expected learning order. Start with `01`, finish all challenges in that context, and then move to the next numbered folder.

When you need to check JavaScript syntax, built-in objects, or method behavior, use the MDN JavaScript documentation:

- [MDN JavaScript Reference](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects)

Each context has its own folder. Inside each folder, every challenge file includes:

- the original exercise link or a local exercise prompt
- a short status field
- a `Solution` section where the completed answer can be pasted

Suggested workflow:

1. Open a challenge file.
2. Access the exercise link or read the local prompt.
3. Solve the exercise.
4. Paste the final JavaScript solution into the `Solution` section.
5. Update the status from `Not started` to `Done`.
