## Prompt

Create a function called `getProfileFields(profile)` that receives an object and returns an array with all property names in that object.

The function must return only the keys, not the values.

## Examples

```javascript
getProfileFields({ name: "Ana", age: 22, city: "Recife" });
// ["name", "age", "city"]

getProfileFields({ username: "dev_jr", active: true });
// ["username", "active"]
```

## Requirements

- Use `Object.keys`.
